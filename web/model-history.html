Model History

Each time the model changes, it is tested the same way and compared with the baseline. The goal is more right answers and fewer tickets that need a person, with no high-risk ticket missed.

Current model against the baseline

A model can look good on tickets it trained on. These are held back from training, so the score is a fair test. Fewer is better, as long as High-risk missed stays at zero. Each ticket a person does not need to check is time saved.

History, newest first

"Right" means the category. High-risk missed and Sent to a person use the 60-ticket test set, written blind and frozen before any measurement. Cards with Approve is the average of 40 full desk runs. A live run uses different tickets, so its numbers differ.
